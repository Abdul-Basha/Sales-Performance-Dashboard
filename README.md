# Sales Performance Dashboard using Excel

## Project Overview

This project analyzes sales data using Microsoft Excel to identify revenue trends, regional performance, and top-performing salespersons.

## Skills Used

* Data cleaning and formatting
* Excel formulas and functions
* VLOOKUP, INDEX and MATCH, XLOOKUP
* SUMIFS, COUNTIFS, and AVERAGEIFS
* PivotTables and PivotCharts
* Conditional formatting and data validation
* Interactive slicers and dashboard design

## Dashboard Features

* Revenue by Region
* Monthly Revenue Trend by Category
* Top 5 Salespersons by Revenue
* Interactive Region Slicer

## Tools

* Microsoft Excel

## Project Files

* `Sales_Performance_Dashboard_Excel.xlsx` — Excel workbook
* `Sales_Dashboard.png` — dashboard preview

## How to Use

Download the Excel workbook and open it in Microsoft Excel to explore the formulas, PivotTables, charts, and dashboard.
